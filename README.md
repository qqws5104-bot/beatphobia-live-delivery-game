# 박스 포장 프로토타입

`index.html`을 브라우저(Chrome 권장)로 열면 바로 실행됩니다. 인터넷 연결이 필요 없습니다.

## 규칙
- 화면에 뜬 순서대로 방향키를 누르고, 마지막은 Space로 테이프를 붙입니다.
- 한 번 틀리면 같은 순서를 처음부터 다시 눌러야 합니다. 실수 횟수는 올라갑니다.
- 타이머는 첫 입력부터 흐릅니다.
- 포기를 누르면 새 상자로 바뀝니다. 포장을 끝낸 뒤에는 Space 또는 "다음 상자" 버튼으로 넘어갑니다.

## 사용 키 안내
- 어두운 청회색 바탕에 작고 납작한 키로 표시해서, 게임 화면의 흰색·주황 키와 구분됩니다.
- 실제로 키를 누르는 동안 해당 안내 키가 파랗게 켜집니다.
- 스타일은 `index.html`의 `.guide` 부분과 `--guide-*` 색 변수에서 바꿀 수 있습니다.

## 조정 값 (`index.html` 안의 `CFG`)
- `ARROWS`: 방향키 개수 (마지막 Space 제외, 기본 6)
