# 확정 층수 택배 · 송장 붙이기 프로토타입

`index.html`을 브라우저(Chrome 권장)로 열면 바로 실행됩니다. 설치나 인터넷 연결이 필요 없습니다.

## 조작
| | 이동 | 선택 / 부착 |
|---|---|---|
| P1 | A · D | Space |
| P2 | ← · → | Enter |

## 규칙
- 확정 층수는 6개(B1, 1F, 2F, 3F, 4F, 5F)입니다.
- 층 고르기: 이동 키로 층을 고르고 선택 키로 확정합니다.
- 송장 붙이기: 송장이 저절로 밀립니다. 이동 키로 점선 구역 안에 맞추고 선택 키로 붙입니다.
- 실패하면 1.2초간 잠기고 같은 층에서 다시 맞춥니다.
- 두 플레이어가 같은 층을 노려도 됩니다. 먼저 붙인 쪽이 그 층을 가져가고, 다른 쪽은 층 고르기로 돌아갑니다.
- 6개 층이 모두 확정되거나 제한 시간이 끝나면 종료됩니다. 많이 확정한 쪽이 승리하고, 동점이면 정확도로 가립니다.

## 조정 값 (`index.html` 안의 `CFG`)
- `SESSION_SEC`: 세션 제한 시간
- `TOL_START`, `TOL_END`: 허용 오차 (층이 확정될수록 좁아짐)
- `DRIFT_START`, `DRIFT_END`: 송장이 밀리는 속도
- `LOCK_MS`: 실패 후 잠금 시간
